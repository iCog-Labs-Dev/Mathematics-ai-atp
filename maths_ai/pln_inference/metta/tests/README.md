# Archived MeTTa examples

`test_gitimport.metta`, the `use-module!` files, and `translator_output/` record the
previous Git-import integration. They are historical evidence, not executable
installation tests. Their absolute paths, imports, and expected scores do not
represent the current local-dependency implementation.

Use `python -m maths_ai.pln_inference.diagnose --output <new-directory>` for native
checks. See [the PLN guide](../../README.md) for configuration and interpretation.
The Python tests here continue testing the Thompson sampler independently.
